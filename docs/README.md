# gisland documentation

The extension guides are written for users of an installed gisland. They do not require knowledge
of the C++ implementation or a source contribution:

- [External modules](modules.md): package layout, Lua API, declarative views, and the JSONL protocol
  for modules written in any language.
- [Themes](themes.md): installation, complete theme structure, semantic roles, fonts, images, and
  reload behavior.
- [`gislandctl`](gislandctl.md): interactive use, automation, JSON status output, actions, and exit
  behavior.

The repository's [default theme](../assets/themes/default.toml) and
[Lua example package](../assets/modules/lua-example/) are complete working references.
